# Overview Figure

`grbc_overview.png` is Figure 1 of **Graph-Reweighted Behavior Cloning with Human Interventions for Precise Robotic Manipulation**, by Xiaoman Li and coauthors.

Paper: https://arxiv.org/abs/2610.20504

The image was rendered from the matching camera-ready PDF on a white background so the original transparency displays correctly in both light and dark GitHub themes. Scientific content, panel layout, labels, and authorship were not changed. The full paper, private experiment images, datasets, and model checkpoints are not bundled.

The Apache-2.0 code license does not relicense third-party pretrained checkpoints. This figure is provided by the paper's authors for the GR-BC project documentation.
